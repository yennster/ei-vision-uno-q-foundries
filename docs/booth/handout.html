SHOW. TRAIN. SHIP. REPEAT.

Powered by Arduino UNO Q + Edge Impulse + Foundries.io
You picked something up at another booth — a squishy, a sticker, a branded mug, whatever. You set it in front of this $40 Arduino UNO Q. The model didn't know what it was at 9 a.m. By the time you finish your coffee, the model knows. So do all the other boards in this booth.

That's a full active-learning loop running, in public, on a tech-conference floor.

The loop, in four moves

①
Show

USB camera + OpenCV motion detector spots a new object. Frame uploads to the Edge Impulse training set.

②
Train

GitHub Actions polls EI hourly. New samples → retrain → build a fresh .eim → tag a release. ~10 min.

③
Ship

Second workflow reacts to the tag, syncs the container into the Foundries factory's containers.git, factory CI builds an arm64 OTA target.

④
Repeat

Every UNO Q in the fleet pulls the target via aktualizr-lite. Devices never get touched. No re-flashing. No SSH.

Why it lands

  • A $40 board, not a $1,000 dev kit. The UNO Q runs Debian on aarch64 — full Linux, full Docker, room for surprises.
  • One workflow, any fleet size. Updating one board and updating ten thousand is the same operation.
  • Active learning isn't theory. The booth's model gets measurably better between coffee and lunch. The version timeline poster is updated live.
